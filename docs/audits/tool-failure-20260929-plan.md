## 2. 增量实施范围

| 编号 | 证据与缺陷 | 修改 | 验收 |
| --- | --- | --- | --- |
| R1 | 手机 62 次未限定服务的 MCP 搜索被旧临时服务缺少凭据阻断，其中包含内置工具误路由 | 内置名称匹配现有权威工具定义；未指定服务时仅检索缓存，显式返回未知、过期目录及下一步动作 | 搜索不启动远端服务、不执行内置动作；指定服务时保留认证和权限错误 |
| R2 | Windows 84 次 inspect 错误退化为 MCP_ERROR，丢失插件可用性错误码 | 保留现有 ToolError 的 code、details、retryable 和 cause | 包装后的插件错误与原对象一致，认证拒绝不转为自动重试 |
| R3 | Windows 12 次搜索失败中 3 次查询以连字符开头；当前 rg 未使用参数终止符 | rg 添加 `--` 和 `--no-config`，错误保留有界 stderr/退出码 | 实际 rg 正确搜索负数与 `-Werror`，外部配置不能改变调用语义 |
| R4 | 文件过滤在 rg 全量输出后才生效；手机有 80 次搜索预算超限，排除目录仍被遍历 | 带过滤条件的请求走现有原生匹配器，精确文件名直接定位，完整排除子树提前剪枝；rg 输出限额与取消边界 | `*.go`/`**/*.go` 语义不变，固定文件搜索不访问无关树，隐藏/忽略/符号链接边界不扩大，输出内存有界 |

　　以上修改沿用现有 Runtime、MCP Manager、文件匹配器和权限入口，不增加第二套任务系统或执行运行时。目录损坏仍返回失败，缓存缺失返回明确不完整结果，不能伪装成“工具不存在”。
