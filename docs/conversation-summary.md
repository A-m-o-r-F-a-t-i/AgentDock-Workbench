# 对话近期运行状态

控制面板“运行中”统计真实对话的近期活动数量，与侧栏活动标记共用 Core 的半开时间窗口：最后一次有效交互起 120 秒内。命令结束后窗口仍有效，窗口到期后后台命令仍可查看和停止，但不继续计入近期运行数量。UI 刷新和异步命令输出不续期。

`GET /internal/runtime/execution` 新增 `conversation_summary`：`recently_active` 为近期活动对话数，`total` 为全部未永久删除的真实对话数，`recent_interaction_window_ms` 为 120000。统计来自同一次读取的调用事实，并使用响应 `server_now`。归档、回收站、已终止对话保留在总数中，不计入近期活动。未归属调用与已永久删除对话不计入两个计数。

`statistics.running`、`statistics.pending` 和 `in_flight` 继续表达调用执行与审批状态，不改变命令生命周期、终止能力、历史筛选和权限。Windows 使用单次总览响应，不再下载完整 selection ID 列表。旧 Core 缺少新字段时显示状态不可用，避免把未知值写成零。

Windows 与 macOS 侧栏不再根据短暂 RPC 状态显示“执行中”或运行调用计数，保留近期活动标记和待审批信息。macOS 时钟刷新同时遵守归档、回收站、终止与未归属状态。共享 Core 统计适用于 Windows、macOS、Android 和 Linux；Android 现有首页只显示已加载的对话/调用条目，没有同名“运行中”计数，本次不改变其调用状态含义。

插入入口 180 秒可用期和未领取补充 300 秒到期规则保持独立。自动回归覆盖边界时间、已完成调用、并发根调用归并、无任务对话、未知与未来时间、后台命令以及管理状态。
