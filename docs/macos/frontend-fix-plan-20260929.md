# macOS 前端隐藏缺陷修复计划

基线：GitHub `A-m-o-r-F-a-t-i/AgentDock-Workbench` 的 `main@de70f5f78b8534259fbd1df70ea0f6cc4a39b4b5`。
执行工作区：OPPO 独立工作树 `22-macos-frontend-fixes`。本地克隆的 origin 指向另一工作树，后续远端校验与推送必须使用用户 GitHub 仓库的完整地址。
交付：实现、回归测试和 PR。不得合并、发布、安装或重启生产服务。

## 1. 修复范围

| 编号 | 修改 | 回归要求 |
| --- | --- | --- |
| MAC-01 | HTTP 与 SSE 使用独立 URLSession；SSE 空闲时限覆盖 15 秒心跳，设置独立的长资源时限；断流通过 REST 重新确认可用性 | 真实 Core 连接持续超过旧 20 秒时限；普通请求仍为短超时；游标与取消保留 |
| MAC-02 | 仅对结果未确定或仍待投递的同一次插入复用 submission_id；观察到终态后清理对应缓存；不批量清除未决键 | 同文重试复用 ID，终态后再次主动发送生成新 ID，切换对话后仍能收敛 |
| MAC-03 | 权限生效值与尚未提交的选择分开，定时渲染不覆盖编辑值 | 选择新模式后连续渲染仍保持选择；切换对话重置；服务端确认新模式后结束编辑 |
| MAC-04 | 输出缓存与具体 payload 描述关联，载荷变化使缓存失效；增加重新读取入口；迟到响应不得覆盖新载荷 | 运行中先读空输出、审批后写回最终输出、读完后重读、取消/切换时的迟到响应 |
| MAC-05 | 只在用户补充选择真正变化时自动切页签 | 选中补充后手动切到任务/权限，重复渲染不抢回页签 |
| MAC-06 | 前端、API 和编辑器统一 8192 UTF-8 字节限制，并显示计数与错误 | ASCII、中文、emoji 的临界字节值；无效输入不发请求且保留草稿 |
| MAC-07 | 更新本地插件包前校验候选包；仅收到确定的来源变更拒绝并经用户明确确认后，提交 confirmed_source_change | 接受/取消重新绑定、无效候选包、其他错误不重试 |
| MAC-08 | 通过可选 include_important 契约，在历史分页配额外保留置顶、正在执行及选中记录 | 第 21 条以后的旧置顶/执行记录不遗漏；不重复；原调用方不启用时语义保持 |
| MAC-09 | 配置入口和连接校验共用 IPv6 主机规范化，构造 URI 时保留方括号 | 实际临时配置文件中的 ::1/[::1]/::/[::]；非回环仍拒绝；IPv4 不回归 |

## 2. 实施边界

- 不修改权限默认值、插入 120/180/300 秒规则、实际投递协议或生产 Core。
- 不弱化已有测试断言。新增原生交互测试覆盖真实渲染及用户事件，不仅验证截图存在。
- HTTP/SSE 继续直连回环、禁止重定向、不使用代理或 Cookie。
- 输出仍按需读取，未展开内容不自动下载。
- 插件来源确认只允许针对明确的来源保护拒绝，网络异常与未知写入结果不得自动重放。
- 共享侧栏新增字段默认为 false，以保持其他客户端现有分页语义。

## 3. 验证与提交

1. 静态差异、格式、国际化键及敏感信息检查。
2. 执行受影响 Go 回归；手机工具链不能执行时如实保留状态，由 GitHub Actions 运行同一提交。
3. GitHub Actions 在 arm64 与 Intel macOS 上运行现有原生回归和新增测试，不安装或发布。
4. 推送独立分支，创建面向 main 的 PR，记录基线、修复映射和真实测试结果。
