- [x] P0：错误恢复引导指向宿主工具命名空间，禁止再走动态 search/inspect；不伪造执行参数、宿主 Schema 已加载或命令已执行。服务层保留真实拒绝和重复诊断，对外工具层将已解决的纯宿主路由记录为成功终止结果，不隐藏请求或业务失败。

## 验收边界

动态 MCP 服务层负责拒绝错误路线并保留重复诊断，AgentDock 对外工具层负责把可信的纯宿主解析表达为成功终止路由，外部宿主负责真正加载 Schema。协议重放与集成测试单独报告，不标称为未经执行的真实模型 A/B 实验。状态断路仅针对内置工具误用，不锁定合法目录读取、参数修正或业务执行。保留认证、权限、用户插入和任务绑定机制。
