# ChatGPT 目标模式

　　Windows 执行中心支持把一个明确的 AgentDock 对话、任务和分支绑定到用户选择的 ChatGPT 对话。托盘中的目标模式服务读取任务运行状态，通过浏览器页面脚本自动续执行，不依赖鼠标键盘、前台窗口或当前选中的执行中心条目。

## 使用方式

1. 在执行中心选择已有活动任务的对话，点击标题右侧“目标模式”。
2. 点击“发现 Roxy”，或者填写已经启用的本机调试端点。读取标签页后手动选择对应的已有 ChatGPT 对话，并勾选对应关系确认。
3. “关闭标签页后，允许在同一浏览器会话中用隐藏页面接续”默认勾选，点击“绑定并开启”后生效。关闭此选项时，绑定标签页消失将暂停目标模式。
4. 同一入口提供“停止目标模式”和“解除绑定”。关闭执行中心窗口不停止已开启目标；退出 AgentDock 托盘进程则停止。

　　自动发送内容固定为：`当前任务尚未完成，请继续任务`。功能不会自行选择任务、猜测对话对应关系、接受网页上的新指令或授予额外设备权限。

## 判定与恢复

| 条件 | 行为 |
| --- | --- |
| 绑定任务为 active，分支为 open，页面已完成上一轮回答，连续静默达到 300 秒 | 发送一次续执行消息，并核对新用户消息的 DOM 回执 |
| 新执行记录、任务更新、回复内容变化、后台命令仍运行、页面生成中、有草稿或待审批 | 不发送，重新累计静默时间 |
| 已发送但没有新的 AgentDock 任务进展 | 保持等待，不按五分钟无限重复发送；真实进展出现后才允许下一轮 |
| 完成、取消、归档、删除，或对话绑定的任务、分支发生改变 | 停止并要求重新明确绑定 |
| 登录失效、页面不再匹配、结构不识别、连接断开、发送回执不确定 | 暂停，不自动重试不确定的发送 |
| 观察间隔超过 45 秒，包括系统睡眠后恢复 | 清空已累计的静默时间 |
| 原标签页关闭，且已允许隐藏页面接续 | 在同一浏览器会话和 browserContext 中创建隐藏页面，重新稳定观察后计时 |
| 浏览器或 AgentDock 托盘重启 | 保留绑定信息并暂停，需手动重新开启 |

　　每 10 秒检查一次，使用单调时钟。五分钟从稳定可观察状态开始累计，因此实际发送时间还包含页面恢复、轮询与发送回执时间。浏览器进程、其本机调试端点和 AgentDock 托盘必须保持运行。隐藏页面不能在浏览器退出后独立运行。

## 实现与边界

　　`GoalModeService` 由 App 持有，使用现有 `ActivityClient` 和运行目录解析。`GoalActivitySource` 读取既有对话、任务、分支、执行概览和后台会话接口，不新增第二套任务运行时，也不把工具 RPC 返回当作后台进程已经结束。

　　`GoalBrowser` 使用本机 Chromium DevTools Protocol；`GoalPageScript` 是唯一的浏览器状态检查、输入、发送和回执脚本。绑定包含浏览器会话、context、target 和规范化 ChatGPT 对话 URL。仅接受 `http://127.0.0.1:端口`，禁止远程地址、代理和重定向，不读取 Cookie、不导出登录凭据、不调用 ChatGPT 私有接口，也不改变浏览器启动参数。

　　关闭标签页的恢复使用 `Target.createTarget` 的 `hidden: true` 和 `background: true`。此目标不出现在浏览器标签栏，生命周期由持续持有的调试连接管理。每次绑定最多恢复一次；隐藏目标再次丢失时暂停。停止监测或退出进程会释放自有隐藏目标。协议依据见 [Chrome DevTools Protocol / Target](https://chromedevtools.github.io/devtools-protocol/tot/Target/)。页面的 `document.visibilityState` 可能为 `visible`，不以此字段判定是否存在浏览器标签窗口。

　　本地设置通过临时文件替换保存，单个运行目录持有独占监测锁，最多保留八个绑定。发送前先持久化不确定意图，失败时不修改浏览器；发送后必须取得新消息回执。不确定意图在重启后保留并暂停。设置保存的是绑定与状态，不保存浏览器消息正文或认证信息。

　　页面适配覆盖本轮实测的 ChatGPT 中文界面，同时保留若干英文及旧版 DOM 标记。页面结构变化、其他浏览器版本、站点登录交互和未识别的附件 UI 需要继续回归；未知状态暂停，不能将本轮样本推广为所有版本均已验证。

## 2026-10-12 设备实测

**环境**：用户正在运行的 Windows Roxy，Chrome/153.0.8010.27；独立创建的 ChatGPT 测试对话。未向真实工作对话发送续执行消息，未安装候选程序或重启生产 Core。

| 项目 | 观测结果与范围 |
| --- | --- |
| 后台页脚本输入、发送、回复读回 | 成功，使用当前登录会话 |
| 原测试标签页关闭后恢复 | 同一浏览器会话创建 hidden target，原标签页不再存在 |
| 真实五分钟等待 | 页面稳定后连续静默 300 秒；测试启动后 314.500938 秒确认发送一次 |
| ChatGPT 回复 | 收到预先约定的“续执行测试已收到” |
| 防重复发送 | 随后继续观察约 30 秒，发送计数保持 1；更长重复轮次由可控时钟回归覆盖 |
| 隐藏目标是否占据浏览器窗口 | 独立 about:blank 隐藏目标探针确认没有对应浏览器窗口，创建前后前台窗口句柄一致 |
| 清理 | 运行器退出后原测试标签和自有隐藏目标均不存在 |
| 真实任务中心接口 | 通过产品 ActivityClient 只读取得当前对话的活动任务、main 分支及 Busy=true 状态 |

　　五分钟发送实测使用固定的“未完成任务”输入源，实际浏览器、登录会话、输入发送、消息回执和等待时间都是真实运行。真实任务接口另行只读验证，未把当前真实开发任务停放五分钟来触发它的自动发送。全程前台窗口恒定没有作为验收结论；上述前台句柄一致仅指独立隐藏目标创建探针。

## 回归命令

```powershell
dotnet run --project desktop/windows/control-panel-goal-tests -c Release
dotnet run --project desktop/windows/control-panel-goal-native-tests -c Release -p:AgentDockRuntimeSplit=true -- dist/goal-mode-layout
dotnet run --project desktop/windows/control-panel-tests -c Release
dotnet build desktop/windows/control-panel -c Release -p:AgentDockRuntimeSplit=true
go test ./internal/activity ./internal/taskstate ./internal/app
```

　　纯逻辑测试覆盖 29 项目标状态与发送策略断言、13 项真实接口字段合同断言。原生测试覆盖显式确认、未自动选择标签、重启暂停、重复实例锁、停止、解除、损坏设置保留，以及常规和最小窗口尺寸。离屏 UI 宿主不启动生产托盘或 Core。既有桌面纯逻辑回归共 972 项断言通过，三个 Go 包回归通过。

　　只读浏览器探针可使用测试运行器的 `--observe`、`--discover` 和 `--hidden-probe`。`--continue` / `--recover` 需要显式 `--confirm-send`，且仅接受标题包含“续执行测试”、初始回复包含“测试已就绪”的隔离对话。运行器使用与产品相同的浏览器适配器及页面脚本。

　　新增测试接入 Windows frontend regression。既有完整 WPF 布局套件要求 GitHub Actions 环境，本地未绕过其运行限制。本机离屏位图渲染返回空白，因此不交付截图或把它作为视觉验收依据；原生测试输出实际窗口几何和绑定状态，完整界面回归留待 CI。候选实现尚未替换正在运行的安装版本。
