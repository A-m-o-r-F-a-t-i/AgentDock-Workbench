# AgentDock 1.1.0

　　相对 1.0.1，1.1.0 首次加入任务活动中心、可恢复任务线程、工作区路由和本地活动接口，并新增 Windows Tailscale Funnel 公网接入。发行范围扩展到 Windows x64 和 ARM64。

## 1. 任务活动中心

　　新增独立任务活动中心，可以从托盘打开。界面按任务和线程展示真实命令、工作目录、运行环境、输出、退出码、耗时、文件修改、工具调用和阶段检查点。

　　活动中心只展示执行记录，不运行模型，也不显示模型隐藏思维。命令停止、复制脱敏命令、打开工作目录、定位修改文件、查看当前 Git Diff 和线程管理都与具体记录绑定。

## 2. 可恢复任务、线程与工作区

- Task 区分成功、取消、归档和解除归档，历史记录继续可查询。
- Thread 支持创建、检查点、切换、阻塞、恢复、分叉与关闭。
- 命令会话固定启动时的任务、线程、步骤和工作区绑定，后续观察、输入和停止自动沿用。
- 旧任务只读加载时映射到 `main`，首次修改时再持久化线程信息。
- 新增 Workspace Registry，以及 `source`、`artifact`、`scratch`、`cache` 和 `external` 路由。
- 带工作区绑定的写入会核对实际路径；工作区外目标需要显式声明。

　　工作区路由用于明确项目和文件归属，不等同于操作系统级 Shell 沙箱。

## 3. 本地活动接口与流式记录

　　持久活动日志采用有界分段、增量输出合并和写入前脱敏。SSE 支持 `Last-Event-ID`、重连去重、心跳和连接释放；历史被清理时明确显示缺口，不伪装成完整记录。

　　活动流、控制和 Diff 接口只允许直接回环访问，并检查本地 Host、Origin、代理头和认证。公网 Tunnel 不能直接读取本地活动输出。

## 4. Tailscale Funnel

　　公网访问新增 Tailscale Funnel。控制面板可以读取已登录客户端的设备域名，显示客户端、设备、域名、密钥到期和 Funnel 状态，并提供检测和启停入口。

　　映射按精确路径和所有权管理，不覆盖其他服务，也不会顺带公开无关的私有 Serve 路径。失败后只恢复 AgentDock 自己的配置和运行状态；卸载不会移除 Tailscale 客户端或其他映射。

　　Cloudflare Quick、Named 和仅本机方式继续保留，安装升级和同版本修复会保存当前公网访问方式、Origin、监听端口和映射所有权。
