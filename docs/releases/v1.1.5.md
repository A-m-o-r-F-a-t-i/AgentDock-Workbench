# AgentDock 1.1.5

　　相对 1.1.4，1.1.5 增加运行中对话的用户补充入口、分级历史列表、任务成功通知和托管 MCP 覆盖，并继续整理深色主题与项目导航。

## 1. 活动时间与中途补充

　　对话活动、允许发送补充和补充等待领取使用三个独立时间窗口：

| 对象 | 条件 |
| --- | --- |
| 对话活动标识 | 最近 120 秒有真实执行更新 |
| 补充输入与终止入口 | 最近 180 秒有真实根工具调用 |
| 已发送补充 | 等待同一对话下一次新工具调用，300 秒后失效 |

　　列表轮询、重连、重放和重命名不会延长活动时间。发送前已经开始的调用不会领取新补充；期限内到达的下一次调用即使稍后才返回，仍可以携带已领取消息。

　　补充草稿按对话保存，支持中文输入法、Shift+Enter 换行和幂等发送。任务变化时暂停投递，终止对话时取消未投递消息。

　　补充以独立可信文本块追加在工具结果之后，保留原有错误、结构化内容、图片和文件。已附加只表示写入响应，不代表模型已经阅读；结果未知时不会自动重放原业务工具。

## 2. 项目与对话列表

　　项目下默认显示近 72 小时最多 5 条对话，可以展开到 15 条和完整历史。近期不足时不拿旧记录凑数，但仍保留历史入口。

　　项目之间独立分页，搜索可以访问历史内容。列表按稳定 ID 增量更新，保留选中项、滚动位置、分组折叠和右键目标，不再周期性清空重建。

## 3. 提示、主题与布局

　　历史保留期限提示保存固定关闭状态，关闭后不会在重连或重启时重复出现。其他连接、权限和保存错误仍单独显示。

　　插件卡片、Skill/MCP 成员、诊断文字和边框使用共享动态主题资源。主题切换不需要重新加载列表或重启 Core，未知 MCP 工具数量不显示成确定的零。

## 4. 任务成功通知

　　应用和托盘独立观察任务成功完成，并在右下角显示一次性通知。点击后定位到具体任务及来源线程，不会跳到同一对话随后启动的其他任务。

　　单个工具、步骤、线程结束和任务取消不会触发成功通知。通知领取状态持久化，多个窗口、刷新、重连和重启不会重复弹出。

## 5. 托管 MCP 覆盖与热更新

　　`mcp_manage` 增加 update 和 reset_override，使用 inspect 返回的 revision 进行并发比较。运行时覆盖只在当前进程有效，持久覆盖保存在宿主配置中，优先级高于插件默认值。

　　连接目标变化会先验证候选配置，再原子切换，并等待旧代调用结束。失败时保留上次可用连接与工具目录。版本和工具数量来自真实 MCP 初始化和目录，不允许用覆盖文本伪造发现结果。

　　已经在当前上下文使用的能力发生变化时，后续响应会提示重新读取相关工具，不会展开无关 Heavy 插件。
