# AgentDock Workbench 1.1.7

　　相对 1.1.6，1.1.7 首次统一使用 **AgentDock Workbench** 产品名，并把 Windows 为主的发行扩展到 Windows x64/ARM64、Linux x64/ARM64 和 macOS Universal。同时加入分层权限、输出续读、插入回执、活动容量与恢复边界等完整能力。

## 1. 产品名称与跨平台发行

　　GitHub Release、安装器和软件界面从本版开始统一显示 AgentDock Workbench。已有命令名、数据目录、服务标识和升级资产名保持兼容，旧版本发行记录不改名。

　　Windows 提供完整 WPF 控制面板和活动中心；macOS 提供原生通用 App；Linux 提供 Core、核心 Skill 和命令行管理包。平台共享同一 Core 数据、权限和活动状态，不建立互不兼容的平行任务系统。

## 2. 分层权限系统

　　权限设置分为三层，并支持全局与工作区继承或覆盖：

| 层级 | 作用 |
| --- | --- |
| Permission Profile | 文件系统、网络和工作区边界的硬上限 |
| Approval Policy | 决定按需审批、拒绝审批或按类别细分 |
| Approval Reviewer | 选择用户审查或独立自动审查程序 |

　　显式 Deny 和 Profile 上限始终优先。`never` 表示拒绝需要审批的操作；自动审查失败、超时、无效或拒绝时不会派发原操作，自动批准也不会转化成永久工作区授权。

　　Windows 设置界面可以编辑三层权限、继承关系和实际审查主体，并修复长短路径别名影响受保护目录识别的问题。

## 3. 活动中心与用户补充

　　用户中途补充在时间线中独立显示，保留正文预览、发送时间和投递状态。可以查看完整正文、复制、取消后续投递或在有效期内重投。

　　新增 `insertion_ack` 回执。未确认消息沿用同一消息 ID，在原有效期内有限重投；重投只附加消息，不重新执行命令、文件修改或业务工具。

　　项目菜单、分页和快速重复触发的竞态得到修复。侧栏移除重复“对话”徽标，搜索框改为“搜索对话”，动作说明统一为明确中文，文件增删统计在简洁和详细模式中保持同一位置。

## 4. 工具输出与续读

　　普通文本输出支持 1,000–100,000 字符上限，默认开启并设为 20,000。设置热更新后只影响后续调用，不重启 Core；规则、Schema、控制信息和用户补充不计入普通文本预算。

　　被截断的原始普通文本可以保存在活动存储中，并通过授权 `read_file` 续读。显示字符预算与续读字节偏移分开，历史记录不会因修改设置而被重写。

　　正文未保存、只保存部分或引用已过期时分别返回明确状态，不会通过重新执行原命令补齐输出。

## 5. 上下文、注册表与客户端状态

　　`agentdock_context` 在读取规则前确定实际工作区，并在一次请求中完成绑定协调。`complete=true` 表示所需组件和绑定已经准备完成，`binding_updated=true` 只描述本次变化，不要求第二次完整加载。

　　注册表在跨进程锁内核验内容指纹并复用快照，权限、归属、删除和终止变化继续检查。缓存代际隔离避免旧快照覆盖新状态。

## 6. 恢复、容量与一致性

　　安装 journal 使用原子发布，备份和暂存验证完成后才切换目标。恢复失败时保留原目录和仍有恢复价值的材料，Windows 权限转换只有在提交成功或恢复成功并复核后才清理备份。

　　OAuth 未完成注册、已授权客户端和活动 Append 分别使用独立容量边界。活动调用在产生副作用前预留终态记录空间；没有容量时拒绝派发，已经提交的结果保持真实。

　　计划任务定义和状态原子保存。恢复时核对任务定义、原任务状态和安全描述符，避免恢复流程意外触发任务。

## 7. 界面与交互

　　活动中心“更多”按钮支持 Enter 和 Space，分页、搜索切换、明暗主题及不同窗口宽度下的状态保持更稳定。

　　任务与调用的进行中操作、导航切换和窗口关闭分别管理取消与回退，旧异步响应不能覆盖新选择。插件展开只显示成员，不改变 Heavy 设置。
