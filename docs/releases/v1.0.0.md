# AgentDock 1.0.0

　　相对 v0.8.3，1.0.0 是当前仓库的首个 1.x Release，集中引入插件与 Heavy 渐进加载、运行配置和 AGENTS.md 上下文能力，并重构 Windows 安装、升级试运行和回滚链路。本版只提供 Windows x64 成品。

> **重要提示**：1.0.0 后续确认存在覆盖安装启动失败、回滚不完整和 PowerShell 黑窗问题。历史版本说明保留这些真实限制；需要安装或升级时应使用 1.0.1 或更高版本。

## 1. 插件、Skill 与 Heavy 渐进加载

　　插件采用 `plugin.json`、`mcp.json` 和 `skills/` 组成的目录结构，将可移植包内容与本机开关、凭据引用和持久数据分离。控制面板可以展开、收起、启停插件及成员，并管理 Heavy 状态。

　　普通插件直接公开启用的 Skill 和 MCP；Heavy 插件先只显示插件摘要，执行 `plugin_load` 后再展开成员和工具目录，减少大型专业插件长期占用上下文。

## 2. 运行配置与 AGENTS.md

　　新增运行配置页面，用于管理默认工作区、AGENTS.md 自动加载、额外指令文件、浏览器程序、可信代理范围、命令环境变量引用以及 ACP 并发和超时。

　　Core 会按全局到项目的顺序加载 AGENTS.md。`agentdock_context(workdir)` 可以按请求读取指定工作区规则，不改变命令默认目录。

## 3. Windows 安装、升级与回滚

　　安装链路增加事务化升级试运行：新版本先在当前用户会话中启动，确认目标版本健康后再提交；失败时恢复旧版本、凭据和用户数据。

- 修正 Task Scheduler COM 参数布局和多参数调用。
- 升级流程使用经过校验的新载荷 Core 执行启动桥接，避免调用错误代际的实现。
- 启动结果使用本次请求专属回执，保留退出码和 UTF-8 诊断。
- 稳定入口只在安装事务、目标版本、目录和阶段全部匹配时放行未提交版本。
- 首次安装、覆盖安装和同版本修复共用恢复闭环。
- 安装目录支持中文和空格，程序目录与用户数据目录继续分离。

## 4. 插件页面与安装目录管理

　　“功能与插件”页面集中管理已安装能力，不再从界面直接安装或更新插件包。全新安装可以选择程序目录；已有安装继续沿用原位置，避免两份程序争用启动项和端口。

　　此前失败事务若仍包含未处理的系统状态，安装器会要求先完成恢复或协调，不会通过删除错误标记伪造恢复成功。
