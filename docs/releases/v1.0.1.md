# AgentDock 1.0.1

　　相对 1.0.0，1.0.1 重点完成插件与 Agent 目录标准化，并修复 Windows 覆盖安装、回滚、后台启动和 Tunnel 生命周期问题，取代 1.0.0 成为可正常升级使用的版本。

## 1. 标准插件与可移植能力

　　当前激活 Skill 使用与 Codex 对齐的可见目录树，插件采用 Agent Plugins 1.0.0、Agent Skills 和 MCP 标准清单。符合规范的插件、Skill 和 MCP 可以直接按标准目录或包复用，宿主继续独立保存版本状态、本机开关、凭据引用和持久数据。

　　Heavy 参数保留在 AgentDock 扩展命名空间中。普通插件直接暴露启用成员，Heavy 插件先显示摘要，按需展开后才读取 Skill、MCP 和工具目录。

## 2. 功能、插件与运行配置

　　“功能与插件”页面统一管理插件、Skill 和 MCP 的展开、启停、成员开关及 Heavy 状态，避免同一成员在多个列表中重复出现。

　　运行配置页面补齐默认全局工作区、AGENTS.md 自动加载、额外指令文件、浏览器程序、可信代理、命令环境变量引用以及 ACP 并发和交互超时等设置。插件、Skill 和 MCP 列表并行加载，单个远程服务变慢或失败时不会阻塞本地能力展示。

## 3. Windows 安装与恢复修复

　　安装器外层命令改由原生 GUI 启动器执行，后台 Core 和 Tray 通过当前用户会话的计划任务启动，避免交互式 PowerShell 窗口和控制台黑框。

- 安装请求使用随机事务 ID 关联回执，旧结果不能覆盖新请求。
- 保留 UTF-8 输出、真实退出码和安装器早期失败诊断。
- 已退出进程遗留的插件库锁可以安全恢复，同进程并发互斥仍保留。
- 新版本只有通过健康检查才提交；回滚恢复 generation、凭据和运行配置后，还会确认旧版本重新健康。
- 覆盖安装、同版本修复和首次安装使用同一恢复闭环。
- 安装失败时保留恢复材料，不把未知终态写成成功。
- 中文和空格路径、静默安装及实际安装日志位置得到统一处理。

## 4. Tunnel 生命周期

　　停止信号可以传递到公网 URL 生成、cloudflared 等待和 Core 配置重载阶段。重复启动会识别当前活动 generation，不会重复创建 supervisor。

　　Core 重载被取消时会执行有界恢复，避免本地 Core 留在离线状态。运行记录增加 supervisor、cloudflared 进程和退出阶段信息，便于判断停止是否真正完成。
