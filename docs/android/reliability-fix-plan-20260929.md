# Android 1.1.8 可靠性修复计划

基线：`de70f5f78b8534259fbd1df70ea0f6cc4a39b4b5`。分支：`fix/20260929-android-reliability`。
范围：上一轮 A01–A11 和浏览器兼容性 R01。只提交 PR，不合并、发布、安装 APK 或操作生产 Core。

## 1. 部署与恢复

| 编号 | 修复要求 | 回归条件 |
|---|---|---|
| A01 | 未决恢复存在时不新建缺失的 data，保持恢复现场，拒绝覆盖未知目标 | 显式回滚与失败升级回滚的隔离、发布窗口中断及重复续作 |
| A02 | 签名和摘要验证后识别相同制品，不覆盖不同版本的 fallback | 同制品不同 ID、重复恢复、同版本不同摘要 |

| A08 | node.json 为唯一端口配置，启动忽略旧 port 文件 | 配置写入失败和遗留端口冲突 |

## 2. 本机守护与回执

| 编号 | 修复要求 | 回归条件 |
