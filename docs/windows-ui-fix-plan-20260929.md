# Windows 前端八项缺陷修复计划

基线：`de70f5f78b8534259fbd1df70ea0f6cc4a39b4b5`。分支：`fix/20260929-windows-ui-safety`。

## 实施范围

沿用现有 WPF、ActivityClient、服务端权限和任务接口；不改生产 Core、不安装、不合并、不发布。

| 编号 | 实施内容 | 回归验收 |
| --- | --- | --- |
| WIN-01 | 批量选择独立版本与查询快照，搜索/视图/手工选择变化取消旧全选，确认框保留范围 | 延迟旧响应、A→B→A、手工选择变化不得提交旧 ID |
| WIN-02 | 分离用户选择与可执行的已加载任务/分支快照，加载期间禁用动作，确认后再次校验固定目标 | 任务/分支逆序返回、确认时切换选择、取消后切走不得操作旧目标 |
| WIN-03 | 终止入口移至对话标题栏，独立于三分钟插入资格 | 179/180/181 秒、后台执行、已终止与回收站 |
| WIN-04 | 插件修改在 I/O 前进入 busy，覆盖开关/Heavy/成员/删除，失败读回 | 慢写期间控件不可编辑，重复进入明确拒绝，失败保留可核对状态 |
| WIN-05 | 定时及手动刷新同时更新摘要与可见详情，保留当前分支与滚动 | 绑定不变而 checkpoint/步骤/里程碑变化时更新 |
| WIN-06 | 初始化每次 await 后校验关闭状态，关闭取消 ready 并解除 timer 处理 | 各初始化阶段延迟后关闭，不复活 timer、不发后续请求 |
| WIN-07 | 保存期间冻结高级设置编辑区并阻止重复提交，失败保留原草稿 | 延迟保存、重复保存、失败恢复编辑 |
| WIN-08 | 菜单捕获显式导出范围，区分正常/未归属/孤立对话 | 右键目标与当前选择不一致、切换选择后仍导出固定目标 |

## 实施顺序

1. 先修 WIN-01、WIN-02、WIN-08 的对象身份与异步提交边界。
2. 修复 WIN-03、WIN-04、WIN-05、WIN-06、WIN-07 的交互与生命周期。
3. 新增使用真实 WPF 控件和内存 HTTP transport 的隔离回归，复用现有测试项目。
4. PR 触发 Windows x64 原生 WPF 回归及 x64/ARM64 编译，保留实际日志。编译通过与原生行为通过分别报告。

## 验证约束

测试不启动 App、托盘、安装器或生产 Runtime，不读取真实令牌。WPF 行为在 GitHub Windows runner 执行；ARM64 若只有交叉编译，不写成 ARM64 原生验收。原有断言不得删除或弱化。
